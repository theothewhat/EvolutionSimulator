This programme is meant to represent the idea of a basic evolution pattern. A species has a random genetic mutation,the genetic mutation is advantageous and therefore they get to reproduce

This project is mainly for me to get to grips with pushing projects to github rather than just using git, and using Nvim as a IDE


My idea involves Organisms being randomly generated with names, with different traits, then there are a limited amount of resources per generation of organisms
The strongest get the resources, and kill the others, allowing them to reproduce and pass down both their last name and potentially some of there traits
